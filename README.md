# Нулевой корпус

Одиночный хоррор от первого лица. В 03:17 двенадцатого ноября 1986 года из заводского городка исчез служебный корпус НИИ «Контур». Десять лет спустя бывшая дежурная Вера Левина слышит на кассете свой голос. Он просит отключить корпус. У забора снова стоит проходная.

Кампания состоит из ста последовательных миссий в десяти главах. Вера проходит по коридорам, собирает вещи исчезнувшей смены, сопоставляет их с уликами и настраивает приборы. Когда реле предупреждает об Обходчике, нужно успеть в боковую комнату. Первое дело начинается у турникета, последнее решает судьбу застрявшей на 03:17 смены.

## Запуск

В переносимом архиве можно сразу открыть в браузере файл `dist/index.html`.

Из корня репозитория запустите на Node.js 18 или новее:

```sh
node server.js
```

Откройте [игру на этом компьютере](http://127.0.0.1:4173). Сервер слушает только петлевой интерфейс. Для другого порта задайте переменную `PORT`. Библиотека Three.js, шрифты и изображение уже лежат в репозитории. Звук синтезируется в браузере.

## Управление

| Действие | Управление |
| --- | --- |
| Идти | WASD, стрелки вверх и вниз |
| Бежать | Shift + движение |
| Оглядываться | Щелчок в сцене и мышь, при недоступном захвате — перетаскивание |
| Осмотреться с клавиатуры | Стрелки влево и вправо, Page Up / Page Down |
| Взять предмет, прочесть улику, воспользоваться прибором | Подойти, посмотреть на объект и нажать E |
| Фонарь | F |
| Журнал с уликами, предметами и ориентирами | J или Tab |
| Пауза | Escape |

На телефоне жест в левой части экрана задаёт движение, в правой поворачивает камеру. Для взаимодействия коснитесь кнопки «Осмотреть». Чувствительность, громкость и строки видеозаписи можно изменить в настройках.

После подбора предмета, чтения улики и завершения миссии прогресс сохраняется в этом браузере. При возвращении вы окажетесь у входа в текущий сектор со своими находками. Сохранения привязаны к адресу игры и профилю браузера.

## Сюжет и устройство кампании

В [сценарии кампании](docs/CAMPAIGN.md) собраны сюжет, десять глав и прохождение всех ста миссий с решениями. Внутриигровой архив позволяет читать завязки дел без просмотра ответов.

- `campaign.js` содержит предметы, улики, вопросы, решения и развязки.
- `world.js` отвечает за движение, коллизии, наведение и Обходчика. `assets/world/` строит коридоры, боковые комнаты и тематическое оборудование из общих модулей.
- `instruments.js` реализует табло времени, цифровой набор, коммутацию и ввод последовательностей. Другие станции предлагают текстовый выбор.
- `main.js` ведёт журнал, переключает задания и сохраняет прогресс.

## Проверка и переносимая версия

```sh
node --test
npm ci
npm run build
```

Первая команда проверяет данные кампании и связность маршрутов. Последние две собирают автономную версию в `dist/index.html`. Скопируйте этот HTML на другой компьютер и откройте в современном браузере. Игра подгрузит код, изображение и шрифты из самого файла.

Three.js распространяется по MIT, шрифты Roboto и IBM Plex Mono — по SIL OFL. Тексты лицензий находятся в `vendor/` и `assets/fonts/`. Фон меню создан для этой игры.

## Публикация

При открытии pull request в `main` и при обновлении самой ветки GitHub Actions проверяет кампанию, собирает автономную игру и запускает её в Chrome. После успешной проверки `main` тот же `dist/index.html` отправляется в GitHub Pages. Правила заданы в [workflow Pages](.github/workflows/pages.yml).

Для домена `zero-corpus.kosarevsky.dev` в настройках Pages репозитория укажите источник **GitHub Actions** и этот адрес в **Custom domain**. В DNS зоны `kosarevsky.dev` запись `CNAME` с именем `zero-corpus` должна указывать на `agent-axiom.github.io`. После выдачи сертификата включите **Enforce HTTPS**.
